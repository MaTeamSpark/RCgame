# Escape to Kerala

*Marketing Analytics presents · Work Hard · Run Faster · Reach Paradise*

A four-stage side-scrolling runner built for RC 2026. Escape your desk, race to the airport, fly to the coast, and reach the Kerala off-site — one jump at a time.

**▶ [Play the game](https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/)**

## Controls

| Stage | Move | Action |
|---|---|---|
| 1 · Office | — | `Space` / `↑` to Jump |
| 2 · Airport | `↑` / `↓` change lane | — |
| 3 · Flight | `↑` / `↓` fly up/down | Hold to keep climbing |
| 4 · Kerala | — | `Space` / `↑` to Jump |

`P` pauses. Mobile shows on-screen buttons.

## How the score works

- **+100** per hurdle cleared
- **+100** for ⭐ stars, **+150** for stage-themed snacks (coffee / gas / banana chips / coconut water)
- Score **carries across stages** on successful transitions
- Score submits to the leaderboard on game over, retry, menu return, or full-journey completion

## Tech notes

- Single self-contained HTML file (~4.5 MB) with all art embedded as base64 PNGs
- Vanilla JS + Canvas 2D, no build step, no dependencies, works offline
- Leaderboard stored in browser localStorage (top 50 kept per device)
